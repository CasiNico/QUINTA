# Pagina demo: Palette Nude + Verdi

Questa è una semplice pagina dimostrativa che usa una palette con:

- Sfondo: "nude pantone" (molto chiaro, non bianco) ~ #F6ECE6
- Bottoni: verde ash chiaro ~ #C8DCCB
- Titoli: verde pino (più scuro) ~ #0F3B2D

File principali:

- `index.html` — pagina HTML
- `styles.css` — stili e palette
- `script.js` — piccolo script per dropdown

Come aprire (Windows):

1. Apri la cartella nel File Explorer
2. Doppio click su `index.html` per aprirla nel browser

Note:

- I colori sono approssimazioni in hex delle referenze richieste.
- Il menu a tendina è gestito via JavaScript; supporta chiusura con Esc e clic esterno.
